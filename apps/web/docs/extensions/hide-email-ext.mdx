---
title: Hide Email
description: Blur selected email addresses and optionally mask IPv4 or IPv6 addresses in web-page text, including dynamically added content, while leaving editable fields unchanged.
---

Hide Email blurs email addresses you select. You can also enable **Hide IP addresses** in the toolbar popup to mask IPv4 and IPv6 addresses in page text. IP masking is off by default. It works on regular pages and dynamically updated pages, while leaving input fields and editable content alone. Hidden addresses appear as random values with the same address format; click one to reveal it and click again to hide it.

## Add and remove addresses

1. Open the Hide Email toolbar popup.
2. Add an email address to the redaction list. The extension validates and normalizes entries before saving.
3. Visit a page containing that address; it will be blurred as the page is scanned.
4. Remove an address from the popup when you want it to appear normally again.

To mask IP addresses, open the popup and turn on **Hide IP addresses**. The setting syncs with your browser profile.

The list is saved with browser sync storage, so it can follow your browser profile when sync is enabled. A page's visible text is scanned locally, including new content added by single-page apps or infinite scrolling.

## Install a local build

1. Clone the [source repository](https://github.com/mynameistito/browser-extensions), then run `bun install` and `bun run prepare:wxt` from its root.
2. Run `bun run --filter hide-email-ext build`.
3. In Chrome, load `apps/hide-email-ext/.output/chrome-mv3` from `chrome://extensions` with Developer mode enabled.
4. In Firefox, select `apps/hide-email-ext/.output/firefox-mv3/manifest.json` through `about:debugging#/runtime/this-firefox`.

## Permissions and privacy

`storage` saves the email list and IP masking setting in `browser.storage.sync`. `<all_urls>` allows the content script to find and blur selected emails and, when enabled, IP addresses on pages you visit. This scan runs locally; the extension does not send addresses or page text to a server. It skips inputs, textareas, and contenteditable fields so it does not alter text you are entering.

## Troubleshooting

- **An address remains visible:** confirm it is in the popup list and appears as ordinary page text, not inside an editable field.
- **A new page element is not updated:** wait for the page's content changes to finish, then check that the extension is enabled for that site.
- **Settings do not sync:** browser sync must be enabled for the profile; local redaction still works on the current profile.

See the [Hide Email source and privacy notes](https://github.com/mynameistito/browser-extensions/tree/main/apps/hide-email-ext).
