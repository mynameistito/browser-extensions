title: Hide IP
description: Blur your public IP address in page text, tab titles, and tooltips, with hover-to-reveal behavior and no page-content uploads.
---

Hide IP looks up your public IP address, then blurs matching text on pages, in browser-tab titles, and in `title` tooltips. Hover over a blurred address to reveal it; move away to hide it again.

## First use

1. Install and enable the extension.
2. Open a page that contains your public IP address. The extension requests the address from the Browser Extensions API, then checks page text for that exact value.
3. Hover over a blurred match to read it. Move the pointer away to blur it again.

The fetched address is cached in memory for 15 minutes. Text in inputs and textareas is left untouched. The extension does not collect or transmit page content.

## Install a local build

1. Clone the [source repository](https://github.com/mynameistito/browser-extensions), then run `bun install` and `bun run prepare:wxt` from its root.
2. Run `bun run --filter hide-ip-ext build`.
3. Load `apps/hide-ip-ext/.output/chrome-mv3` in Chrome through `chrome://extensions` with Developer mode enabled.
4. For Firefox, select `apps/hide-ip-ext/.output/firefox-mv3/manifest.json` using `about:debugging#/runtime/this-firefox`.

Without a local Chrome signing key, a local Chrome build gets a temporary extension ID. See the [source README's persistent Chrome ID setup](https://github.com/mynameistito/browser-extensions/tree/main/apps/hide-ip-ext#persistent-chrome-extension-id) for steps to keep the ID stable across builds. Firefox uses a fixed Gecko ID and does not need this key.

## Permissions and privacy

The extension requests `storage` and permission to contact `https://browser-ext.mynameistito.com/*`. It asks the Browser Extensions API at `https://browser-ext.mynameistito.com/api/v1/ip` for the public IP address. Cloudflare processes that request and can see the connecting public IP; the API returns the address to the extension, which matches it against page text locally. The extension does not upload page contents.

## Troubleshooting

- **Nothing is blurred:** check that the page contains the same public IP returned by the API and reload after enabling the extension.
- **The lookup fails:** check network access to `browser-ext.mynameistito.com` and try again later.
- **Text in a form is visible:** inputs and textareas are intentionally excluded.

See the [Hide IP source and privacy notes](https://github.com/mynameistito/browser-extensions/tree/main/apps/hide-ip-ext).
